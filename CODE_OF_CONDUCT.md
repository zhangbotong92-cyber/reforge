# Code of Conduct

## The short version

Be decent. Critique code, not people. Assume the other person is trying to help.

This applies to issues, pull requests, discussions, commit messages, and anywhere the
project's name is used to represent it.

## What is not acceptable

- Harassment, insults, or personal attacks of any kind.
- Sexualised language or imagery, and unwelcome attention.
- Publishing someone's private information without permission.
- Sustained disruption: derailing threads, reopening settled decisions without new
  information, or spamming maintainers.

## Scope note specific to this project

REFORGE touches prompt reverse-engineering, provenance, and synthetic media. People
disagree sharply about that space. Disagreement is welcome; implying another contributor
is acting in bad faith is not. Bring evidence — a fixture, a number, a repro — and the
argument resolves itself.

**Do not** post someone's private images, prompts, or metadata while filing an issue.
Redact first. If a report needs the original file, say so and wait for a maintainer to
provide a private channel.

## Enforcement

Report problems to the maintainers via a private message or by opening an issue titled
`conduct: <one line summary>` with no details in the body — a maintainer will reach out.

Maintainers may respond with a warning, a request to edit a comment, a temporary block,
or a permanent ban, depending on severity and pattern. Decisions are made in private and
reported publicly without personal details.

## Attribution

This is a short, project-specific code of conduct rather than the Contributor Covenant,
because the useful part here is the media-handling rule above. If you want a
battle-tested general template instead, see
